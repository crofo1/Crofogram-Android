# 🚀 Crofogram (Android)

Telegram asosidagi tezkor, qulay va maxsus sozlamalarga ega mijoz ilovasi (Telegram Client).

## ✨ Asosiy Qulayliklari
- **Tablar (Vkladkalar)**: Shaxsiy, guruhlar, kanallar, botlar, o‘qilmagan xabarlar alohida toifalarga ajratilgan.
- **Ghost Mode (Ko‘rinmas rejim)**: Xabarlarni ko‘rsatmasdan o‘qish, yozmoqda holatini yashirish.
- **Anti-Delete & Message History**: O‘chirilgan yoki tahrirlangan xabarlarni saqlab qolish imkoniyati.
- **Cheksiz hisoblar**: 3 tadan ko‘p hisob ulash imkoniyati.
- **Maxsus dizayn va mavzular**: O‘zingizga moslashtiriladigan zamonaviy interfeys.

## 🛠 Qurish (Build)
Ushbu loyiha avtomatlashtirilgan GitHub Actions orqali kompilyatsiya qilinadi.
Har bir `push` amalga oshirilganda, GitHub Releases bo‘limida tayyor `.apk` fayli avtomatik paydo bo‘ladi.
